# Minimal Enemy Sample Set — Egyptian

Same purpose and constraints as [MinimalSampleSet-Greek.md](MinimalSampleSet-Greek.md) and [MinimalSampleSet-Norse.md](MinimalSampleSet-Norse.md): not a real roster, just enough to unblock a first playable Anubis slice and validate combat against Scale's actual kit. Paired with Egyptian since it matches Anubis, the third Blessing taken through this same playable-slice process.

Mirrors the Greek and Norse sets' structure and power level directly (same HP tiers, same intent-count shapes) so all three read as siblings. Continues the deliberate debuff-variety pattern: Greek's debuffer applies **Drained**, Norse's applies **Sundered**, this one applies **Exposed** — all three universal debuffs now covered, no two sets using the same one.

**Same standing rulings as the Greek and Norse sets apply**: enemies tied to stage mythology, the intent-reveal system assumed, Training Dummy shared as-is.

## Sanity Checks

**Covers the same core intent patterns as the Greek and Norse sets**, at matching power level (Ushabti Sentinel ≈ Hoplite Skirmisher ≈ Draugr Reaver; Set's Cultist ≈ Harpy Screecher ≈ Seidr Hexer; Scarab Swarm ≈ Viper Brood ≈ Wolf Pack) — enough to exercise Scale's bidirectional read (a debuffing enemy pressures a Reaper-leaning Scale, punishing enemies benefits Ascendant/Order pushes) without needing a full roster.

**Deliberately not included**: a boss, and anything that reads or manipulates Scale directly — same Hook 2 deferral as the Greek and Norse sets.

**Not attempted**: numeric tuning against Anubis's actual kit — placeholder numbers sized to match the other two sets' already-placeholder scale, not independently validated.
